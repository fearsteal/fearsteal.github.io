HOW TO JOIN THE BATTLEFIELD

  1. Launch Minecraft Java or Minecraft Bedrock.
  2. Navigate to Multiplayer ➔ Add Server.
  3. Enter Server Address: play.fearsteal.fun
  4. For Bedrock users, set Port to: 19132
  5. Hit Join, execute /register or /login in chat, and begin your hunt.
