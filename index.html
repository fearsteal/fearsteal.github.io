Getting Started

HOW TO JOIN & PLAY

Connect with any official Minecraft Java or Bedrock client in 6 simple steps.

01

Launch Minecraft

Open your Minecraft Java Edition or Bedrock Edition client (1.19 - 1.20+ supported).

02

Multiplayer Menu

Click on Multiplayer or the Servers tab in your Bedrock menu.

03

Add Server

Click "Add Server" and set the name to FearSteal Network.

04

Enter IP Address

Address: play.fearsteal.fun (Bedrock Port: 19132).

05

Join Server

Select FearSteal from the list and hit "Join Server" to enter the lobby.

06

Start LifeSteal

Pick your starter kit, claim territory, and prepare to battle for hearts.

Network Guidelines

SERVER RULES

Violations result in warnings, temporary bans, or permanent network blacklists.

1. Cheating & Hacked Clients
Using any hacked client, auto-clicker, baritone, X-ray texture packs, or PvP macros is strictly forbidden. Any unfair combat advantage results in an immediate permanent ban.
2. Bug Exploitation & Duplication
Exploiting game duplication glitches, chunk busters, portal traps, or invulnerability bugs is disallowed. Report any found exploits to staff for reward bounties.
3. Harassment, Doxxing & Threats
DDoS threats, releasing personal information (doxxing), hate speech, or excessive toxicity in public chat or voice channels will result in an immediate blacklist and report to authorities.
4. Respect Staff & Event Rules
Follow instructions given by Helpers, Moderators, and Admins. Disobeying staff rulings or interfering in official server tournaments will result in disciplinary action.
