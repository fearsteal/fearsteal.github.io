HOW TO JOIN & PLAY

Connect with any official Minecraft Java or Bedrock client in 6 simple steps.

01

Launch Minecraft

Launch Minecraft on PC, mobile, or console (Bedrock or Java edition).

02

Open Multiplayer

Open the Multiplayer menu or select the Servers tab in Bedrock Edition.

03

Select Add Server

Select "Add Server" to configure your direct connection.

04

Enter Server Details

Address: play.fearsteal.fun | Port: 19132.

05

Click JOIN SERVER

Save the server entry and click JOIN SERVER.
