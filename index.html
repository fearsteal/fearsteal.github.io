HOW TO CONNECT

Join in seconds on Bedrock (Mobile/Console/Windows) or Java Edition

Bedrock Edition (PE / Console)

  1. Launch Minecraft on your phone, console, or Windows 10/11.
  2. Click Play → Navigate to the Servers tab.
  3. Scroll down and click Add Server.
  4. Enter Server Name: FearSteal
  5. Server Address: play.fearsteal.fun
  6. Port: 19132
  7. Click Save and Join Server!

Java Edition (PC / Mac)

  1. Launch Minecraft Java Edition (Version 1.20+ recommended).
  2. Click Multiplayer → Add Server.
  3. Server Name: FearSteal Network
  4. Server Address: play.fearsteal.fun
  5. Click Done, select FearSteal, and jump right in!
